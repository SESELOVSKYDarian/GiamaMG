# MG React (Vite + Tailwind)

Proyecto React separado a partir del `index.html` que me pasaste.

## Requisitos
- Node 18+
- npm o pnpm

## Pasos para correr
```bash
npm install
npm run dev
```
Abre el enlace que te muestra Vite (por defecto http://localhost:5173).

## Build de producción
```bash
npm run build
npm run preview
```

> Las imágenes y algunos íconos se cargan desde URLs externas para mantener el ZIP liviano.
